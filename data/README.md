# Data

This folder contains reference and processed data files used in the RASHAD IVI project.

## Files Included

| File | Description |
|------|-------------|
| sampled_preauth2.csv | Processed sample of pre-authorization requests |
| Data_dictionary.xlsx | Column definitions for all datasets provided by Bupa Arabia |
| Provider_Info.xlsx | Hospital and clinic reference information |

## Raw Data Notice

The original raw datasets provided by Bupa Arabia are not included in this repo due to file size limits and data sensitivity. They consisted of anonymized SAS files covering claims, member demographics, pre-authorization requests, and call center records spanning 3 years.
